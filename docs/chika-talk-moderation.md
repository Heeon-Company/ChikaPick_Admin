# 치아톡 제재 확인·이력

기존 신고 상세 폼과 브라우저 확인창을 유지한다. 제재 적용 시 API의 읽기 전용 `actions/preview`를 먼저 요청하고, 대상·선택 조치·사유·누적 횟수·예상 실제 제한·한국시간 종료일·내부 사유·사용자 안내를 확인창에 표시한다. 경고 선택도 누적 정책에 따라 제한으로 이어질 수 있다. 콘텐츠 복원은 이용자 제재를 해제하지 않는다.

확인 취소·조회 실패·조회 중 상세 닫기/화면 이동은 적용 요청을 보내지 않는다. 확인창은 서버 조회 시점 기준 예상 결과이며, 최종 DB 처리는 처리 시각과 동시 조치에 따라 달라질 수 있다. 동일한 요청 ID가 이미 적용됐다면 과거 결과 확인으로 표시하고 기존 멱등 재시도 경로를 유지한다. 입력 내용이 바뀌면 다른 요청 ID를 사용한다.

처리 이력에는 운영자, 조치 시각, 당시 전후 상태와 제한 종료를 추가한다. 과거 이력이 현재도 적용 중이라는 표시는 하지 않으며 현재 제재는 상단 요약에서 확인한다. 과거 스냅샷이 없으면 `상태 기록 없음`으로 표시한다. 내부 사유와 사용자 메시지는 기존처럼 분리한다.

`npm test`의 `chika-talk-moderation.test.ts`는 확인 문구·기간·해제/복원·재시도·과거 상태 표시를 검사한다. 서버 계산과 SQL의 일치 검증은 API의 `chika-talk-operation-notifications.test.ts`에 있다. `npm run lint`, `npm run build`도 실행한다. API를 먼저 배포해야 하며 DB migration은 추가하지 않는다.
