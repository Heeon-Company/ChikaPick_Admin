# 운영현황의 일반 사용자 가입 수

2026-10-06 추가. 기존 인증된 `GET /api/v1/admin/console`의 metrics에 `일반 사용자 가입 수`를 추가한다. 값은 patient_profiles가 등록된 사용자 중 users.deleted_at이 없는 현재 계정 수다. Auth 계정은 Partners/Admin 초대나 미완료 인증에도 생성되므로 Auth 전체 및 기본 patient 역할만으로 가입 수를 세지 않는다. 환자 프로필 없는 치과/어드민 계정과 임시 가족 구성원은 제외한다. 탈퇴는 기존 경로가 환자 프로필을 삭제하므로 제외된다. 치과/어드민 역할을 겸하더라도 실제 환자 프로필이 있으면 한 번 센다. 차단/잠금은 가입 계정을 제거하는 동작이 아니므로 포함한다. 과거 탈퇴 이력을 포함하는 누적 통계나 기간별 가입 통계는 이번 범위에 없다.

API는 Admin 권한 확인 후 patient_profiles → users의 inner join 및 deleted_at IS NULL로 PostgREST HEAD exact count를 요청한다. 환자 정보를 내려받지 않고 최근 사용자 100명·PostgREST 행 제한과 독립적으로 전체 건수를 집계한다. 실패하거나 count가 없으면 요청을 실패 처리하며 0을 만들어내지 않는다. 기존 console의 no-store/권한/오류 계약을 유지한다. DB 스키마/권한/데이터 변경이나 신규 마이그레이션은 없다.

Admin 처리 현황의 첫 카드로 표시하고 클릭 시 기존 치카픽 계정 조회로 이동한다. 접근성 설명의 단위는 명이며 천 단위 구분을 적용한다. 초기 로딩과 이전 API처럼 해당 metric이 없을 때는 `—`, 실제 빈 집계는 0이다. 데스크톱은 5개 카드, 기존 태블릿/모바일의 2열/1열을 유지한다.

검증: 집계 쿼리와 0/1,205 및 실패/누락, metrics 응답 회귀 테스트. 실제 로컬 PostgreSQL/PostgREST에서 합성 계정 1,205개를 생성하여 삭제 사용자 1명과 탈퇴 프로필 제거 1명 제외 후 1,203명을 HEAD exact count로 확인하고 원복했다. 임시 SELECT 권한도 원복했다. API 전체 본 테스트 697개 중 694개 통과/기존 3개 건너뜀, Admin 165개 통과. 양쪽 린트·프로덕션 빌드도 통과했다. 실제 Chrome에서 1,203명/0명/미제공 값 표시, 계정 조회 이동, 데스크톱 5열·모바일 1열을 확인했고 브라우저 오류는 없었다. 캡처는 Admin의 로컬 artifacts/admin-patient-count-view에 보관한다. API → Admin 순서로 main에 커밋/푸시하며 기존 Git 연동 운영 배포 상태를 확인한다.
